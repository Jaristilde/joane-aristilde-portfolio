My Process

How I Build My Apps

I start with research, a business case, and system design. Then I plan the agent workflow, build, and check the result.

1. Research the need

I study the industry, compare competitors, and check what the technology can do. With Manus or Perplexity, I research my target customers, their needs, and gaps in the market.

2. Build the business case

I define the problem, the customer, and the value the app should offer. I map customer needs, test assumptions, and plan the business model and market fit. I usually start in Cursor to organize research, interview notes, and test cases in folders I can inspect and manage.

3. Design the solution

Before coding, I plan the system architecture: how the interface, data, APIs, and services fit together. I map the user journey, define the product and its connected services, and build a prototype to test the idea.

4. Choose tools for the work

About 90% of my projects involve a mix of Cursor, Claude Code, and Google Antigravity with Gemini. I choose based on the task, file access, token allowances, and cost. Cursor helps me organize and inspect files; Antigravity supports further building; Claude Code helps with deeper programming and execution. Each project has its own starting point.

5. Give agents separate duties

I build an agent workflow, also called multi-agent orchestration. A UX agent focuses on user flows, a security agent reviews risks, and a lead agent coordinates tasks and dependencies. Agents work on independent tasks in parallel. Tasks with dependencies wait for the needed work. I review outputs and redirect or replace an agent when needed.

6. Connect, test, and review

I configure API connections, keys, and payment services myself. I do not share API keys with agents in prompts. I use Cursor, Visual Studio, or Antigravity to inspect my files. Across projects, I use Supabase or Firebase, Netlify for hosting, and Render for services such as email. I sometimes use Codex for QA and a second opinion.

I started this portfolio in Cursor and finished it with Codex by ChatGPT. My prompts come from a plan; I own the decisions and final review.
